Solar analytics database reset

From PowerShell:

cd D:\ERP\solar
$secureUrl = Read-Host 'Enter the direct Solar PostgreSQL connection string' -AsSecureString
$urlPointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secureUrl)
try {
  $env:DATABASE_URL = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($urlPointer)
} finally {
  [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($urlPointer)
}
try {
  node .\scripts\reset-analytics.cjs
} finally {
  Remove-Item Env:DATABASE_URL -ErrorAction SilentlyContinue
}

The script shows the destination and requires an explicit confirmation before
resetting the Solar analytics tables. It does not reset unrelated database tables.
